## 🌐 Use Almac as your default browser
- Almac now registers as a web browser on macOS. It appears in **System Settings › Desktop & Dock › Default web browser**.
- New **Set Almac as default browser** button in **Settings › General**. It shows a ✓ once Almac is the default.
- Links from other apps (Mail, Slack, Notes, Teams…) and `.html` files open as a new tab in Almac, even when Almac is not running yet.

## Install / update
- On **v1.3.1 or v1.3.2**: **Almac Browser › Check for Updates…** → **Update & Restart**.
- After updating, open **Settings › General** and click **Set Almac as default browser**, or choose Almac in System Settings.
- New install: `Almac-Browser-1.3.3-arm64.dmg` (Apple Silicon) or `Almac-Browser-1.3.3-x64.dmg` (Intel).
